## 🔗 Related Resources

### 🎙️ Shinyrealtime
- **[Shinyrealtime](https://github.com/posit-dev/shinyrealtime)** — Package from Posit for integrating OpenAI's Realtime API with Shiny apps in both R and Python. It enables natural, interruptible voice conversations with an AI assistant, plus tool calling. (I'm a contributor!)

### 🗣️ Deepgram
- **[Deepgram](https://deepgram.com)** — Speech AI platform with APIs for speech-to-text transcription, text-to-speech, and audio intelligence features such as speaker labels, summaries, topics, and sentiment.

### 📝 Voice Notes Demo
- **[Voice Notes Demo](https://github.com/lsilva-sfk/voice-notes-demo)** — Browser-based voice notetaker built with Shiny for Python and Deepgram. Record a note and get back a speaker-labeled transcript, summary, topics, and sentiment. Notes are saved locally and can be searched or exported to Markdown.

### 🐉 Voice Quest Demo
- **[Voice Quest Demo](https://github.com/lsilva-sfk/voice-quest-demo)** — Short fantasy adventure you play by talking, built in R with shinyrealtime, ellmer, and OpenAI's Realtime API. An AI narrator improvises the story, while the map, items, dice, and hearts are plain R code the narrator can only change through tool calls.
